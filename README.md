# kinopoisk-shortcut

Расширение добавляет на страницу фильма или сериала на Кинопоиске кнопку,
которая открывает тот же путь на другом сайте:
`kinopoisk.ru/film/518042/` → `kinokino.win/film/518042`.

## Установка

Скачать `kinopoisk-shortcut-*.zip` со страницы
[релизов](https://github.com/Echways/kinopoisk-shortcut/releases/latest).

- **Chrome, Яндекс Браузер, Edge:** распаковать архив, открыть
  `chrome://extensions`, включить «Режим разработчика», нажать «Загрузить
  распакованное расширение» и выбрать папку.
- **Firefox:** открыть `about:debugging#/runtime/this-firefox`, нажать
  «Загрузить временное дополнение» и выбрать архив. Дополнение живёт до
  перезапуска браузера.

## Настройка

В [config.js](config.js): `LABEL` — текст кнопки, `TARGET_ORIGIN` — сайт,
`OPEN_IN_NEW_TAB` — открывать ли в новой вкладке. После правки обновить
расширение и перезагрузить вкладку.
