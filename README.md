# kontramarka

![Кнопка-билет «Смотреть, 0 ₽»: в покое и с надорванным корешком при наведении](assets/button.png)

Расширение добавляет на страницу фильма или сериала на Кинопоиске билет,
который открывает тот же путь на другом сайте:
`kinopoisk.ru/film/518042/` → `kinokino.win/film/518042`.

При наведении корешок билета надрывается, по клику отрывается, а когда
возвращаешься на вкладку, печатается новый.

## Установка

Скачать `kontramarka-*.zip` со страницы
[релизов](https://github.com/Echways/kontramarka/releases/latest).

- **Chrome, Brave, Яндекс Браузер, Edge:** распаковать архив, открыть
  `chrome://extensions` (в Brave — `brave://extensions`), включить «Режим
  разработчика», нажать «Загрузить распакованное расширение» и выбрать папку.
- **Firefox:** открыть `about:debugging#/runtime/this-firefox`, нажать
  «Загрузить временное дополнение» и выбрать архив. Дополнение живёт до
  перезапуска браузера.

## Настройка

В [config.js](src/config.js): `label` — текст на билете, `price` — надпись на
корешке, `targetOrigin` — сайт, `openInNewTab` — открывать ли в новой вкладке.
После правки обновить расширение и перезагрузить вкладку.
